線型結合せんけいけつごうlinear combination

いくつかのベクトルvectorをそれぞれ定数倍ていすうばいscalar multiplicationして足たし合あわせることを、線型結合せんけいけつごうlinear combinationといいます。A linear combination is formed by multiplying each of several vectors by a scalar and adding the results.それぞれのベクトルvectorに掛かける数かずが、係数けいすうcoefficientです。The number multiplying each vector is called its coefficient.

スパンspan

係数けいすうcoefficientを自由じゆうに変かえて、線型結合せんけいけつごうlinear combinationで作つくれるベクトルvectorをすべて集あつめたものが、元もとのベクトルvectorたちのスパンspanです。The span of a collection of vectors is the set of all vectors that can be formed as linear combinations of them, allowing the coefficients to vary freely.係数けいすうcoefficientを一組ひとくみだけ決きめて得えられるベクトルvectorと、そのすべての可能性かのうせいを集あつめたスパンspanを区別くべつしましょう。Distinguish a single vector obtained from one choice of coefficients from the span, which contains all possible results.

たとえば平面へいめんplaneでは、0でない一本いっぽんのベクトルvectorのスパンspanは、原点げんてんoriginを通とおる一本いっぽんの直線ちょくせんlineです。For example, in the plane, the span of one nonzero vector is a line through the origin.同おなじ方向ほうこうや逆方向ぎゃくほうこうのベクトルvectorを何本なんぼん加くわえても、このスパンspanは変かわりません。Adding any number of vectors in the same or opposite direction leaves this span unchanged.平行へいこうparallelでないベクトルvectorを加くわえると、スパンspanは平面へいめんplane全体ぜんたいになります。Adding a vector that is not parallel to that line makes the span the entire plane.

一次独立いちじどくりつと次元じげんlinear independence and dimension

このように、ベクトルvectorの本数ほんすうが増ふえても、スパンspanの次元じげんdimensionが増ふえるとは限かぎりません。Increasing the number of vectors does not necessarily increase the dimension of their span.スパンspanの次元じげんdimensionは、元もとのベクトルvectorたちから選えらべる一次独立いちじどくりつlinearly independentなベクトルvectorの最大本数さいだいほんすうで決きまります。The dimension of the span is the largest number of linearly independent vectors that can be selected from the original collection.一次独立いちじどくりつlinearly independentとは、選えらんだどの一本いっぽんも、残のこりのベクトルvectorの線型結合せんけいけつごうlinear combinationでは作つくれないということです。The selected vectors are linearly independent if none of them can be formed as a linear combination of the others.
