# Independent accepted-source/map prefix review

Scope: base 903b2ab plus engine parse/session.rs and parse/build.rs in files.json. The two production files were copied raw before review. No production or Git changes by reviewer. Dependency and scratch source hashes are recorded separately.

Static result: no blocking defect found. Machine.imported is private, never deserialized or reconstructed from ParseProgress echoes. Initial and Foreign arena insertion precharge a [usize;2] slot. Returning from a Foreign frame removes exactly that arena cursor. Await and NeedMore retain the owned Machine; native and external resumptions use that private Machine after the existing echo and limits checks. Retry initializes a new Machine/arena rather than carrying old cursor positions into a different source revision.

The accepted collector starts with the previous accepted source/map vectors. Successful builtins prefix their new artifacts with the old checkpoint; ordinary reader checkpoints carry the accepted vectors into the next operation; terminal replies move the resulting vectors without sorting or truncating their prefix. Diagnostic/report collector APIs only append newly captured source declarations. The engine keeps a checkpoint backup until the next accepted reply arrives. Imported bounds are updated only after source and map import both finish. A failed import is terminal; the partial retains the same valid sources/maps that were successfully copied before the stop. The next step may stop before head publication, but there is no externally reusable cursor which could bypass omitted artifacts.

extend_sources now skips temporary-index construction for an empty delta after polling. It is an arena-construction helper, not a public validator for arbitrary source tables. Nonempty suffixes still pass the same source/revision, digest, URI, clone, and allocation checks. Public insertion order and map deduplication remain unchanged. The cursor counts the accepted vector length, including duplicate declarations; it does not confuse that count with the deduplicated arena source count.

Independent runtime observation (scratch only): before each engine accept, assert that the new accepted sources/maps start with the old full vectors; assert imported stack length equals active arena stack length and all bounds fit the accepted vectors. These observers read state only and do not mutate Budget or output. Their CPU cost is not a production performance measurement. Original production bytes are preserved in original/.
