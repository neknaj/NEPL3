## Invariant audit

check_provider still resolves the provider signature before the new shortcut. Matched checks end, UTF-8 boundary, value type, state type and view offset before it. Transform Complete checks its output type and view offset. Non-Stopped overflow and duplicate accumulated overflow are rejected before it. report() still checks saved/returned/current Usage, diagnostic/event counts, trace metadata and the ordinary typed Report validation. NoMatch/NeedMore retain their original strict empty-artifact/report conditions and expectation validation; their reports have no locations needing a derived-source resolver.

combined() formerly built a source store from the saved snapshot, declared request closure and accepted current closure before every result. Its independent responsibility for new declarations remains intact whenever any added source, mapping, view element/root, fact, diagnostic or event exists. Failed always retains full resolver construction because primary/recovery may use sources even when other fields are empty. Empty typed payload values are not required: the payload is still validated against the provider output schema. Arbitrary typed data is not automatically a source-position use under the Reader artifact contract.

The saved prefix is privately owned. ReaderSession::read_with_report is crate-private, reached from the validated tokenizer's AcceptedReport; public read starts empty. Tokenizer read_seed validates accepted-source conflicts/admission and accepted report before creating that Reader machine. Provider results pass check_provider before append_artifacts commits any new source/map; rollback restores a previously valid ReaderCheckpoint rather than importing arbitrary new tables. Public Reader resume compares the complete echoed continuation before using its private saved slot. Native callback resume is crate-private to the owning tokenizer. TransformReplyContext is issued only from ReaderSession pending_transform; its portable validate() still reconstructs/admit-checks the saved source closure before calling check_provider. Therefore the new shortcut does not turn a raw NDF reply or caller continuation into a trusted prefix.

The empty branch reads no new source positions. It does not make ambient sources or arbitrary payload-owned source tables authoritative. New conflicting declarations and future map cycles continue through the full combined+artifacts path. BuiltinText seed maps remain valid-by-construction with freshly admitted generated source identity; this is distinct from claiming every seed came through the generic artifact validator.
