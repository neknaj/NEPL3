## Code and contract reasoning

SourceSnapshot storage and SnapshotData fields are private and immutable. Callers can obtain a clone or independently reconstruct checked content; they cannot create arbitrary pointer-keyed source proofs. SourceAdmission is not Clone and its shared Vec is private. The cache holds owning Arc references, so a dropped external source cannot free an admitted address and let a different allocation inherit its hit. Mutable access to an admission ledger serializes mutation; shared snapshots themselves are immutable.

A hit is valid only in this admission object. As before this object is the caller's operation ledger; reusing an entire ledger while declaring a new operation is not equivalent to constructing a new SourceAdmission. The cache does not introduce a public budget-bound proof or eliminate the documented operation-boundary obligation. SourceAdmission import, new independent decoding and non-atomic builds retain the original ID/revision/digest/URI/source-byte checks.

Before the first hit or miss search, budget.poll preserves sticky cancellation. The corrected binary-search charge is bit_length(cache_len), which bounds all halving iterations and depends only on size; a miss then precharges cache_len+1 for insertion/reference retention rather than the allocator-dependent insertion position. low+(high-low)/2 stays within the vector; the maximum legal Vec length also bounds the len+1 arithmetic. Cache allocation is charged before admit_parts. admit_parts completes its own admission bookkeeping only after all fallible charges. Only after it succeeds does the non-fallible logical publication insert the owning Arc. The cap sweep independently observes both old-prefix preservation and absence of a newly admitted ID after failure.

The prior implementation's per-comparison and actual shift-position Work was insufficient for existing equal-operation Usage expectations because pointer order changed those amounts. Root's size-derived charge fixes that concrete issue while still precharging an upper bound before any search/shift. No new public schema, pointer ABI, serialized cache, unsafe code or core I/O was added. This review does not approve later native Reader suspension changes or claim the large Doc now completes.
