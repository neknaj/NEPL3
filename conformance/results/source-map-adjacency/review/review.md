# Independent SourceMap outgoing adjacency review

Fixed 0b4f7e32e5480cb08ab6a2cfb121b8e33fa196d7 versus main 4e18cc1. The production change is private snapshot_dag in core/origin.rs; maps.rs adds two managed tests. Both original and fixed source trees were independently captured/verified using Git bytes. Only scratch tests were added. Commands, target directories, deadlines (600 seconds), tool versions, source hashes and executable hashes are recorded. No live production or Git edits were made.

The coarse snapshot graph remains only an acyclicity shortcut. Source/target span closure and Exact byte equality still precede graph reasoning. Full SnapshotId comparison retains opaque source ID, revision and digest identity; private adjacency indices do not become public source identities. A coarse cycle still reaches the unchanged pointwise fallback, where byte vertices and insertion anchors are distinct, Exact preserves displacement and Transformed relates whole fragments. No coarse cycle is returned as a definitive Cycle by this optimization.

Every new snapshot appends one head. Each edge appends its target and previous head before publishing that edge index as the source's head; following links therefore refer only to earlier valid edge entries. Duplicate edges are neither discarded nor coalesced: incoming counts and decrements both include every edge. A target is enqueued only on its last decrement; all predecessor depths have then contributed to its maximum. Independent roots/joins preserve longest DAG depth. Exhaustion during local index construction or traversal cannot publish a ValidatedSourceMap or append a candidate Mapping. The per-map/edge Work and head/edge Allocation charges precede their new mutations; visited Nodes/active caller Depth remain charged. Existing allocation conventions and checked/saturating overflow handling are retained. Physical allocator failure and exhaustive isize capacity were not injected; actual 32-bit WASI execution was performed.

Native and wasm32-wasip2/Wasmtime each passed the entire core suite (78 managed tests) and three independent tests: 81 per target. Existing interval-cycle, insertion-anchor, forward-overlap, transformed product shortcut, ownership/declaration and containment tests ran. The independent pointwise Boolean reachability oracle enumerates 256 edge subsets in forward/reverse/duplicate-and-rotate orders: 768 inputs, 504 valid and 264 Cycle, on both original and fixed production. These include legal coarse cycles, same-snapshot shifts, joins, transformed fragments, distinct anchor/content vertices, and two revisions of the same Unicode SourceId. Missing a required revision is rejected. Semantic Cycle is not converted into a sticky resource failure, and input mapping arrays remain unchanged.

A separate seven-vertex DAG combines parallel duplicate edges, two roots, shorter and longer routes, a join and a shortcut. All three input orders report relative depth five plus caller depth five and seven visited nodes. Four resource sweeps (Work/Allocation/Nodes/Depth), six caps and three orders produce 48 sticky stops and 24 successes, restoring caller depth on all paths. Cancelled input consumes no resources. Failed and stopped SourceMap::insert preserve previously accepted containment; a later valid candidate succeeds after semantic Cycle with a fresh budget. No SourceBytes/output/diagnostic/event charge is invented for this already-created source geometry proof operation.

The same public star probe ran unchanged against original and fixed production with the same limits. Width 1024/2048 Work changes from 1855984/5996154 to 808432/1803898 on both targets. The original 2.7 ratio bound fails and the corrected one passes, checked explicitly by finalize.py; the observation test itself records these metrics and does not claim the old ratio passed. The exact reduction is E*(V-2), matching removal of V full edge scans plus addition of one per-input-edge charge.

Allocation intentionally increases. Native 1024/2048 is 57384/114728 -> 81976/163896; WASI is 32792/65560 -> 45088/90144. For every case the increase exactly equals V*sizeof(Option<usize>) + E*(sizeof((usize,Option<usize>))-sizeof((usize,usize))). Native head/extra-edge sizes are 16/8; WASI 8/4. Limits were held constant before/after, and these are synthetic graph operation limits, not increases to production document caps.

No blocking finding remains in this change. The private ordered identity index still shifts entries on insertion; this review does not claim globally linear total Work for every identity/insertion order. Only repeated unrelated edge traversal is removed. General Doc corpus completion, full source-map proof serialization, real hardware execution and production release/CI status are outside this independent test scope. Public schema and pointwise fallback code are unchanged.
