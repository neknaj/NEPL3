# Multiple Sentence paragraph projection review

Fixed commit f96e1ba31f006e9e7ea212224106a42d14d67648, base 8a81522. The entire 2296-file Git snapshot is bound by sources.json. The three changed paths are projection implementation, its managed tests, and spec21. Independent tests were added only to this scratch workspace; production files and Git were not edited.

The implementation keeps paragraph traversal outside sentence traversal and carries only previous-code state across the items. It emits no delimiter at a Sentence boundary. Outer Text whitespace checks apply to the paragraph's first/last Sentence; internal whitespace is retained. Each item must still be a nonempty Sentence. Break remains restricted to a Sentence's interior and refuses adjacent whitespace or Break; this is the explicit bounded contract rather than an implicit flattening of all paragraph children. Nested Paragraph and Parallel cannot pass the Sentence check. A previous code cannot be hidden by an empty Text, because empty Text itself fails. The new loop charges Work in sentence_part before accessing each node and retains the existing output/allocation precharges and prepare validation.

The renderer identifier is updated to markdown/4 in the writer and specification. No schema/data model change or native pointer contract is introduced; the affected operation is the tools host Markdown projection. Narrow refusal of annotations, mixed nested flow and unsupported blocks remains separate from full Doc capabilities.

Independent CommonMark event expectations were handwritten for six Sentence sequences, each inside an ordinary paragraph and an unordered list item (12 valid source cases). They cover consecutive Japanese sentences, three internal spaces formed across a boundary, standalone whitespace-only middle Sentences including NBSP, code containing backticks and spaces, all-space code, escaped punctuation, interior HardBreak, and code separated by an authored space. The event comparator preserves block start/end, text content and spaces, code contents and HardBreak, and refuses unexpected SoftBreak or HTML events. It only joins successive Text events, whose segmentation is parser-internal. The expected data is not a copy of generated output.

Twelve independent negative source cases cover empty paragraph/empty Sentence, outer whitespace, code-code adjacency across a boundary, attempted empty-text separation, beginning/end Break, Break-adjacent spaces, nested Paragraph and Parallel. Typed actual parse/lower/markdown additionally checks six zero-resource limits (Source, Work, Depth, Nodes, Allocation, Output) plus cancellation. Every failed operation returns typed sticky Stopped, keeps the borrowed document unchanged and exposes no partial output. A fresh normal operation then succeeds. Output accounting includes preparation's own canonical hashing as well as the produced Markdown bytes, so it is not incorrectly asserted equal only to String length.

References read independently: [CommonMark 0.31.2 paragraphs](https://spec.commonmark.org/0.31.2/#paragraphs), [code spans](https://spec.commonmark.org/0.31.2/#code-spans), [hard line breaks](https://spec.commonmark.org/0.31.2/#hard-line-breaks), and [textual content](https://spec.commonmark.org/0.31.2/#textual-content). Paragraph endpoint trimming motivates the outer-boundary refusal; internal spaces and code padding are independently checked through actual pulldown-cmark parsing. A Sentence boundary does not create a Markdown line ending, whereas an explicit Doc Break does.

Execution is recorded by run.py in full command/log/hash files, using separate native and wasm32-wasip2 targets, Rust/Cargo1.97.0 and Wasmtime44.0.1. Each Cargo subprocess has a 600-second deadline. The root's CI and unrelated output/legacy-anchor or human-review acceptance are not inferred from these scoped tests.

Final result: independent2 and managed projection10 passed on both native and WASI. All 2296 original snapshot source hashes were rechecked unchanged. No new blocking finding was identified in this bounded sentence-sequence projection change. The independent probes needed no expectation correction after execution.
