# Probe refinement and limits
The new stress probe initially ran both the native reader host and the per-token owned exchange host with 64 sentences plus 65536 trailing spaces. The owned host stopped with WorkLimit at cursor624 (Work99949455, Allocation346114056 native process; WASI Allocation268048728). A no-padding 64-sentence variant also stopped on the owned host: AllocationLimit cursor734, Work9959457, Allocation499999991. These are not passes and no production limit was raised. Existing ordinary owned/native equality tests remain. The final stress probe uses the native parsing host then transports the same complete syntax through actual NDF CBOR and a fresh receiver before Doc lowering; it does not claim the per-token owned exchange stress case now fits.
An initial payload byte ceiling of8192 was not derived from schema cost and failed for the host's source identities/views. It is replaced by a relational invariant: each short sentence payload is smaller than the surrounding 64KiB source. The full source itself remains byte-exact in the declared owner; serialization of the old full-source payload cannot meet that condition. No generated golden or production quota was changed.
The semantic order assertion traverses the Article/Body/Paragraph/Sentence edges rather than relying on arena allocation order.
