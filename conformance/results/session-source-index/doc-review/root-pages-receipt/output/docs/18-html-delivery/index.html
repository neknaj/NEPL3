18. HTMLを先行利用せんこうりようする実装段階じっそうだんかい

2026-09-07の追加指示ついかしじにより、Doc入力にゅうりょくからHTMLまでを先行せんこうして利用可能りようかのうにする。基準きじゅんとして提示ていじされた933f0bbへ戻もどさず、既存きそんのlower::document・labels::check・plain_text・source printerを再利用さいりようする。Mathのarena・shape・lower・codecは、進行中しんこうちゅうの表示用ひょうじよう実装じっそうを利用りようする。source printerをHTML rendererへ読よみ替かえない。

実装依存じっそういぞん

正式せいしきタスク段階だんかい成果物せいかぶつと終了範囲しゅうりょうはんい
T22H0Doc用ようmarkup、文書ぶんしょcheck・prepare、URI・asset、renderer、17章しょうの型かた・codec・制約せいやくを具体化ぐたいかし、対応たいおうする公開こうかいAPIの実装前提じっそうぜんていを揃そろえる。
T23H1既存きそんのparser・lower・labelsを使つかうDoc単独たんどくHTML、検査済けんさずみpage・asset解決かいけつ、markup・doc-html、安全あんぜんなserializer、suiteとCLIを実際じっさいに利用りようする入口いりぐち。
T24H2Math表示用ひょうじよう構造こうぞうとbinding、独立どくりつMathML、型付かたつきTeX、Node host KaTeX、式しきごとのfallbackを、実じつNEPL3入力にゅうりょくから接続せつぞくする。
T25H3純粋じゅんすいTEA、共通きょうつうWasm、Worker生成せいせい、隔離かくりpreview、同どうartifactのexportを、Nodeとの比較ひかくと3 browserで検証けんしょうする。

依存いぞんはT22→T23→T24→T25の順じゅんに成果物せいかぶつを供給きょうきゅうする。ここでの矢印やじるしは実装順じっそうじゅんを表あらわす。design/tasks.jsonのdepends_onでは、後段こうだんが前段ぜんだんを参照さんしょうする。T22は先行せんこうfoundation・Doc・Mathの実じつAPIを検証けんしょうして利用りようするが、T01〜T09の全体完了ぜんたいかんりょうを待またせない。T23は未対応みたいおうembedを型付かたつきで拒否きょひし、T24でMathの実解決じつかいけつを追加ついかする。空からのfragmentで段階だんかいをまたがない。

T10・T11・T13・T15・T17・T18は先行経路せんこうけいろを再利用さいりようして、当初とうしょの全責務ぜんせきむを実装じっそうする。Math evaluate、Circuit、LSP、汎用はんようprovider、4言語げんごUI全体ぜんたい、Pages全受入ぜんうけいれ、T21文書移行ぶんしょいこうは残のこる。T16はT25と既存きそんの最終依存さいしゅういぞん、すべてのrequired受入条件うけいれじょうけんを要求ようきゅうする。先行利用せんこうりようの成功せいこうから、既存きそんタスクや受入群全体うけいれぐんぜんたいをpassedにしない。

H0/H1の契約けいやく

Docの既存きそんarenaは表ひょう・list・page link・relative link・external link・imageなどを保持ほじするが、構造こうぞうproofやCheckedLabelsは完全かんぜんなPreparedArticleではない。文書検査ぶんしょけんさは、表示対象ひょうじたいしょうlanguage・parallel policy、外部がいぶpage・asset・foreign requirementsを明示めいじする。prepareは対象たいしょうdocumentのidentity、全要求ぜんようきゅう、解決結果かいけつけっかの型かた・位置いち・資源閉包しげんへいほうresource closureを照合しょうごうする。backendへ未解決みかいけつslotやhostの任意にんいHTMLを渡わたさない。

markupは、table・header・cell、ordered・unordered listとstart・checkbox、img・alt・caption、一般いっぱんlinkに必要ひつような要素ようそ・属性ぞくせい・内容ないようモデルを、閉とじた型かたとして持もつ。同どうartifactのanchor、page ID、相対そうたいpath、external URI、asset参照さんしょうを区別くべつする。危険きけんscheme、path traversal、重複ちょうふくpath、未宣言みせんげんasset、偽にせdigest、wrong slotを拒否きょひし、I/O権限けんげんはhostに残のこす。

Paragraphを入いれ子このpへ機械変換きかいへんかんせず、文ぶんのrunと子こblockのwrapperを使つかう。Sentence間かんに空白くうはくを追加ついかしない。Ruby・Anno、Parallel、heading、空からの表ひょう、list start、codeの改行かいぎょう、画像がぞうの代替説明だいたいせつめいを保持ほじし、ブラウザparserのtree補正ほせいで意味いみが変かわっていないか確認かくにんする。一般いっぱんDocとKaTeXの双方そうほうを、検査済けんさずみmarkupとserializerへ通とおす。

H2/H3の契約けいやくと検証けんしょう

17章しょうを適用てきようする。数式すうしきの正本せいほんは構造こうぞうであり、本文ほんぶんのdollar探索たんさく、MathMLからのTeX推測すいそく、source printer文字列もじれつを数式すうしきとして利用りようしない。非結合ひけつごうoperand、負号ふごうと累乗るいじょう、多文字たもじUnicode記号きごう、片側かたがわfence、Doc注記ちゅうきの忠実性ちゅうじつせいを共通試験きょうつうしけんへ結むすび付つける。表示ひょうじのためにevaluateを実行じっこうしない。

実じつ.nepldからHTMLまでのpositive・negative、MathML-only、KaTeX不在ふざい、optional module失敗しっぱい、局所失敗きょくしょしっぱいと全体ぜんたいStopped、安全性違反あんぜんせいいはん、asset不足ふそくを検証けんしょうする。NodeとDOMなしの実じつWorkerで、固定版こていばん・入力にゅうりょく・設定せっていが同おなじ正準せいじゅんmarkup・manifestを生成せいせいすることを比較ひかくする。

Chromium・Firefox・WebKitで、script禁止きんしかつsame-origin権限けんげんなしのpreview、CSP・CORS・font・非ひroot path、古ふるい返信へんしんの拒否きょひ、停止ていしとepoch、同どうartifactのexportを実行じっこうする。書かき出だし済ずみHTMLのJavaScript無効表示むこうひょうじ、offline bundle、zoom・狭せまい幅はば・印刷いんさつ・アクセシビリティtreeを確認かくにんし、DOMの存在そんざいだけを視覚組版しかくくみはんの成功せいこうにしない。WebKit自動試験じどうしけんとSafari・iOSの実機確認じっきかくにんを区別くべつする。

各段階かくだんかいは、実じつAPI・command・source・spec・target・ログ・独立どくりつレビューと未検証範囲みけんしょうはんいを記録きろくする。既存きそんbootstrap、Doc source printer、source・Origin、予算よさん、no_std・WASIの回帰かいきを維持いじする。ローカルでの成功せいこうは、Pages公開こうかいの証拠しょうこではない。

正式文書せいしきぶんしょのDoc移行いこう

T23で必要ひつような表現ひょうげんが使つかえるページから、T21の棚卸たなおろし・変換へんかんを進すすめる。数式すうしきを含ふくむspecは、T24の実生成経路じつせいせいけいろを使用しようする。T21の完了依存かんりょういぞんをT24・T19へ接続せつぞくし、Math評価ひょうか・Circuit全体ぜんたいの完成待かんせいまちでDoc正本化せいほんかを遅おくらせない。ページ単位たんいの意味いみ・リンク・安定あんていID・生成物対応せいせいぶつたいおうとbootstrapの条件じょうけんは、16章しょうのまま維持いじする。README・AGENTSなどのMarkdown入口いりぐちは、必要ひつように応おうじて.nepld正本せいほんから生成せいせいし、二重にじゅう手書てがき保守ほしゅをしない。
